# capture-inspiration

捕捉创作奇点——那个让这个故事必须被写出来的核心冲动。

## 步骤

1. **引导作者说出奇点**：用开放问题引导，不限定形式：
   - 什么画面、问题、情感或矛盾让你想写这个故事？
   - 如果这个故事只留下一句话，那句话是什么？

2. **提炼奇点**（1–3 句，不超过 100 字）：
   - 核心冲突或张力
   - 主人公面临的不可逃避的处境
   - 让读者必须继续读下去的钩子

3. **入库**：
   ```
   novel-cli stage set-inspiration --content "<奇点内容>"
   ```

4. **确认** — 展示入库内容，询问是否继续到 `/draft-premise`。
