# Claude Code 四原语能力边界（参考）

> 用途：本项目软层原语分配判据的事实依据。来源为 Claude Code 官方文档梳理，非本项目设计基线。
> 对应 CLAUDE.md「软层原语分配判据」：跨阶段不变式忘了就崩 → Rules；必然发生的确定性机械动作 → Hook；某阶段才触发的多步流程 → Skill；读完即弃、会撑爆主上下文的监测/校验 → Subagent。

## Hook

**触发方式**：固定生命周期事件（PreToolUse / PostToolUse / SessionStart / UserPromptSubmit / FileChanged 等）

**能做**：
- 在工具执行前拦截并阻断（exit 2）或放行
- 向上下文注入额外信息（`additionalContext`）
- 以 shell 命令、HTTP POST、MCP 工具调用、LLM 评估等形式运行
- 配合 matcher 过滤特定工具/会话来源/错误类型

**不能做**：
- 无控制终端（不能访问 `/dev/tty`）
- 无法跨会话持久化状态（无状态）
- 不能运行超过 30s（`UserPromptSubmit` 会阻塞模型处理）
- 输出不能超过 10,000 字符
- 复杂 Bash 命令在 if 条件中解析不可靠（失败时放行）

**判据**：必然发生的确定性机械动作 → Hook（容错降级 `exit 0`，绝不阻断写作）

## Skill

**触发方式**：用户手动 `/skill-name` 调用，或 Claude 自动识别相关任务时触发

**能做**：
- 封装多步骤流程或参考资料，按需懒加载（用到才进上下文，区别于 CLAUDE.md 全量加载）
- frontmatter 控制调用模式：自动 / 仅手动 / 优先手动
- 在主 agent 上下文或独立 subagent 中运行
- 携带配套模板、配置等支撑文件
- frontmatter 可标 `once: true`，自动调用时每会话只跑一次

**不能做**：
- 不能跨会话持久化状态（文件式，每次新鲜加载）
- 不能强制拦截或阻断动作（那是 Hook）
- 不能扩展 Claude 本身没有的工具权限

**判据**：某阶段才触发的多步骤流程 → Skill

## Rule（CLAUDE.md / `.claude/rules/`）

**触发方式**：会话启动时自动加载进上下文

**能做**：
- 给出每次会话都生效的持久指令
- frontmatter `paths:` 按文件路径范围加载
- 拆分为多个主题文件按需加载
- `@path` 语法引入其他文件
- 通过 managed settings 定义组织级策略；随 git 仓库跨 worktree/分支生效

**不能做**：
- 不能执行代码或产生副作用（只是 Claude 会读的文本）
- 不能强制执行（软约束，非硬策略）
- 不能自动持久化学习内容（那是 auto memory）

**判据**：跨阶段不变式、忘了就崩 → Rules（须短，≤200 行/文件）

## Subagent（Agent）

**触发方式**：Claude 自主判断委托，或经 Skill/workflow 显式派发

**能做**：
- 隔离执行，拥有独立上下文窗口和自定义系统提示
- 限制可用工具集（最小权限）
- 路由到更快/更便宜的模型处理特定工作
- 并行派发多个独立任务
- 保护主上下文不被大量探索/检索内容撑爆

**不能做**：
- 子 agent 之间不能直接通信（独立工作，回传结果）
- 不能跨会话持久化（除非写入文件）
- 不能在主 agent 未授权下执行越权破坏性操作

**判据**：读完即弃、会撑爆主上下文的监测/校验 → Subagent

## 对照速查

| 维度 | Hook | Skill | Rule | Subagent |
|------|------|-------|------|----------|
| 触发 | 生命周期事件 | 手动/自动识别 | 会话启动 | Claude 自主委托 |
| 执行 | 同步阻塞 | 主上下文顺序执行 | 仅注入文本 | 异步隔离 |
| 强制性 | 硬（可拦截） | 软（流程建议） | 软（文本指令） | 中（工具范围隔离） |
| 上下文代价 | 按次调用 | 懒加载 | 启动时全量 | 零（完全隔离） |
| 有无状态 | 无 | 无 | 无（但持久存在） | 无（结果回传） |
