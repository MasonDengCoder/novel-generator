# 铁律（常驻，任何阶段均适用）

1. **唯一 CLI 接口**：与硬层交互只允许通过 `novel-cli <子命令>`，禁止绕过 CLI 直接读写 DB 或设定文件。
2. **正文不入库**：DB 只存 `prose_ref`（弱路径）和 `word_count` 遥测，生命周期层不生产、不读取正文本体。
3. **不可越级修正**：章节级只能标记；遁出/改主线须走四级阶梯（章标记→事件轻修→卷系统处置→周期归档）。
4. **元素唯一入口**：所有元素（支线/伏笔/爽点/承诺/涌现/弧线/线索绑定）读写经 `element_manager.py` 分发，不直接 import 处理器，不直接拼 SQL。
5. **设定即视图**：世界圣经（Bible）无独立存储，是 DB 的派生渲染，禁止独立持久化。
6. **容错降级而非阻断**：hook 等异常时静默降级（`exit 0`），绝不因工具故障中断写作。
