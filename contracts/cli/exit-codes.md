# CLI Exit Codes Contract

> **本文件是 `novel` CLI 退出码语义的唯一事实来源（SSOT）。** 仓库内其余文档（含 `docs/`）不得重复定义退出码语义表，只能引用本文件。
> 退出码类别是稳定契约。来源：`CLAUDE.md` §9、§10，cli-contract spec。
> 任何硬阻断 MUST 以非零退出码返回，不得静默降级为提示。

退出码语义分两层：**§A 生效契约码**（有实现 + 契约测试背书，Spec 可依赖）与 **§B 预留码**（登记语义意图与归属切片，未固化前 Spec 不得依赖）。

> **V2 默认（05 治理默认化）**：默认错误协议为 V2，进程退出码与 `--json` 信封 `exitCode` **由错误类别派生**（`ErrorCatalog` 类别 → 固定类别码），不再按实体细分。默认路径下，正文 hash 失配（`content_modified_externally`）属 `integrity` 类别 → 退出码 `5`；章节不存在（`chapter_not_found`）属 `not_found` 类别 → `6`；非法状态转换（`invalid_state_transition`）属 `precondition` 类别 → `3`。
>
> **V1 弃用兼容路径**：§A 中按实体细分的退出码（`11` 文件不存在 / `20` 章节不存在 / `21` 内容已被外部修改 / `41` 非法状态转换 / `42` 线索名称冲突 / `43` 主线节点不存在 / `44` 线索不存在 / `45` 涌现不存在 / `46` 绑定已存在 / `47` 涌现已归档）为 V1 协议遗留，仅在调用路径**显式选择 V1** 时生效；其 `ErrorObject` 与 per-entity 退出码逐字保持 V1 回归基线。默认路径不再产生这些细分码。V1 的物理移除由独立变更执行（须满足 `contract-v2-governance` 三条件齐备准则）。
>
> 映射权威源为 `ErrorCatalog`（错误 ID → 类别 → 退出码）与 `crates/novel-cli/src/errors/mod.rs::exit_code()`（V1 兼容）；文档与代码冲突时以代码为准改文档。错误码字符串侧详见 `error-codes.md` §A。

## §B 预留码

> 以下码位登记语义意图与归属切片方向，**对应切片实现并通过测试前不生效**，Spec MUST NOT 依赖其语义。预留码不是当前生效契约。

| 退出码 | 语义意图 | 归属切片方向 |
|---|---|---|
| `8` | 并发锁获取失败 | `s02-chapter-content-core` 或 `s04-state-machine-and-verdicts` 的写命令写锁竞争 |
| `9` | 生命周期复杂度评估阻断 | `s06-destiny-weaving` 的涌现复杂度评估返回 `blocking` 等级时阻断关键推进 |

### 预留码升格路径

某预留码对应的切片实现并通过契约测试后，在归档该切片时把该码从 §B 移至 §A，标注为生效契约码，Spec 方可依赖其语义：

- `8` → 由 `s02-chapter-content-core` 或 `s04-state-machine-and-verdicts`（首个引入写锁竞争的切片）实现时升格
- `9` → 由 `s06-destiny-weaving`（涌现复杂度评估）实现时升格

> 升格时须同时在 `errors/mod.rs` 的 `ExitCode` enum 增加对应变体、补充 golden example 与契约测试，方可视为生效。

### `novel chapter status`

| 退出码 | 场景 |
|---|---|
| `0` | 成功推进状态 |
| `2` | 参数错误：`<id>` 缺失或 `<target-status>` 非四态之一 |
| `3` | 前置条件阻断：世界未初始化、非法路径、门禁未满足、终态不可转换 |
| `20` | 章节不存在 |
| `21` | 内容已被外部修改（hash mismatch） |
| `70` | 内部/存储错误 |

典型阻断场景：

- **非法路径**：`outline → approved`（跳过 `drafting` 与 `review`）等，返回退出码 3。
- **门禁阻断**：进入 `review` 时正文未写入、存在 hard 违规、裁决未达成、裁决或检查 stale，进入 `approved` 时门禁不再满足，均返回退出码 3。
- **终态不可转换**：从 `approved` 推进至任意状态，返回退出码 3。
- **外部修改**：正文 hash mismatch，返回退出码 21（优先于门禁判定）。

### `novel chapter context`

| 退出码 | 场景 |
|---|---|
| `0` | 成功渲染（含空 fragments、无数据层 omitted） |
| `2` | 参数错误：`<chapter-id>` 缺失、`--view` 缺失或非三枚举之一、`--budget` 缺失或非正整数（`usage`） |
| `3` | 前置条件阻断：世界未初始化（`world_not_initialized`）；或预算不足以装填必需 P0/P1_min（`context_budget_exceeded`，复用前置条件阻断退出码 3，靠错误码区分场景） |
| `20` | 章节不存在（`chapter_not_found`） |
| `21` | 内容已被外部修改（hash mismatch，`content_modified_externally`，先于 budget 检查） |
| `70` | 内部/存储错误（`storage`） |

> 预算超限（P0/P1_min 超预算）是"可恢复前置阻断"：退出码复用 3（前置条件阻断类别），错误码用细分 `context_budget_exceeded` 区分场景（与 `world_not_initialized` 等同属 `precondition_blocked` 通用码的细分码）。不新增退出码数值，避免扩大 §A 退出码集合。Spec 据错误码区分"硬前置阻断"与"预算不足可恢复（调高预算或拆章）"。

| 退出码 | 场景 |
|---|---|
| `0` | 封卷检查通过（干运行或已推进状态） |
| `2` | `<volume-id>` 缺失或非法 |
| `3` | 前置条件阻断：章节未 approved、涌现未处置、目标未达成、卷已封闭 |

典型阻断场景：

- **章节状态阻断**：卷内存在非 `approved` 状态的章节。

- **卷已封闭**：卷状态为 `sealed` 或 `archived`，不可重复封卷。

## Export & Verify Commands

### `novel export volume`

| 退出码 | 场景 |
|---|---|
| `0` | 成功导出（含未归档卷的 warning） |
| `2` | `<volume-id>` 缺失或非法 |
| `3` | 世界未初始化 |
| `6` | 卷不存在（`volume_not_found`） |
| `70` | 内部/存储错误 |

### `novel export chapter`

| 退出码 | 场景 |
|---|---|
| `0` | 成功导出 |
| `2` | `<chapter-id>` 缺失 |
| `3` | 世界未初始化 |
| `11` | 正文文件缺失（`file_not_found`） |
| `20` | 章节不存在（`chapter_not_found`） |
| `21` | 内容已被外部修改（`content_modified_externally`，hash mismatch） |
| `70` | 内部/存储错误 |

### `novel export full`

| 退出码 | 场景 |
|---|---|
| `0` | 成功导出（含 hash 失配 warnings、空世界） |
| `2` | 参数错误 |
| `3` | 世界未初始化 |
| `70` | 内部/存储错误 |

### `novel verify integrity`

| 退出码 | 场景 |
|---|---|
| `0` | 全部分项通过 |
| `2` | 参数错误 |
| `3` | 世界未初始化（`world_not_initialized`） |
| `5` | 状态不一致：stale 裁决、归档卷内非 approved 章节等（`state_conflict`） |
| `11` | 正文文件缺失（`file_not_found`） |
| `21` | hash mismatch（`content_modified_externally`） |
| `70` | 悬空引用（`not_found`）或内部/存储错误（`storage`） |
