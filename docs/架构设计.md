# 架构设计 · novel-generator

> 概要设计文档，**M2 冻结的设计基线之一**（宏观蓝图）。模块/表级细化见 `docs/详细设计.md`。
> 上游依据见 `docs/需求说明书.md`；方法论与原语映射见 `docs/创世观对应关系.md`。
> 对应代码库：`novel-generator`（npm workspaces monorepo）。

---

## 1. 三层职责边界

```
openspec/                       ← 方法论层（最慢变，冻结为规格）
packages/novel-spec/            ← 软层：Claude Code LLM harness 控制系统
packages/novel-lifecycle-cli/   ← 硬层：生命周期 + 创作元素管理
```

依赖方向**单向**：软层 → 硬层。硬层对软层零感知。软↔硬唯一接口 = `novel-cli <子命令>`（bin 脚本带 shebang `#!/usr/bin/env python3` + `chmod 755`）。完整安装时由 npm 软链到全局 PATH，目标项目内直接 `novel-cli <子命令>` 执行（**无需 `python3` 前缀，目标项目内无 `scripts/` 硬层副本**）；CLI 默认对 CWD 下的 `index/novel.db` 操作，单一全局二进制服务所有项目。仅「无 LLM 环境单独安装」时才复制一份自包含副本到 `<target>/scripts/`。

| 层 | 包 | 职责 | 对应需求 |
|----|----|------|---------|
| 方法论层 | `openspec/` | 把《创作即创世》冻结为规格，最慢变 | FR-1（方法论冻结） |
| 软层 | `@novel-generator/spec` | LLM harness 控制系统，驱动 LLM 产出正文并适时调用硬层；不存储创作状态 | FR-1.1、FR-5 |
| 硬层 | `@novel-generator/lifecycle-cli` | 零 LLM 依赖的确定性状态机，持有唯一数据源 | FR-1.2/1.3、FR-3、FR-4 |

贯穿全系统的核心判断：**LLM 记忆不可靠，凡"长程必须记住、忘了就崩"的东西全部下沉成确定性 DB 数据兜底。**

## 2. 技术选型

| 层 | 技术 | 选型理由 | 对应约束 |
|----|------|---------|---------|
| 硬层运行时 | Python 3.8+，标准库 | 零依赖，安装即用，sqlite3 内置 | NFR-1 |
| 硬层数据 | SQLite 单文件 | 无服务进程，随项目目录携带，git 可追踪 | DR-1 |
| 软层执行环境 | Claude Code（LLM harness） | skill/agent/hook 均为 LLM 可读 Markdown | FR-1.1 |
| 进程通信 | Node `execFileSync` → `novel-cli`（全局 PATH，自带 shebang） | 同步阻塞，JSON stdout，无 RPC 框架，无需 `python3` 前缀 | NFR-1 |
| 包管理 | npm workspaces | 两个子包共享根 `node_modules`，一条命令安装 | FR-2.1 |

## 3. 原语分配总原则（软层）

把方法论的每条规则按"何时进入 context、由谁执行"分配到 Claude Code 四原语：

| 原语 | 何时加载 | 由谁执行 | 适合承载 |
|------|---------|---------|---------|
| Rules（CLAUDE.md） | 每轮常驻 | LLM 自觉遵守 | 跨所有阶段、违反即崩的铁律 |
| Hooks | 事件触发 | 脚本（LLM 之外） | 必须每次确定性发生的机械动作 |
| Skills | 按需加载 | LLM 读后执行 | 某个创世阶段的多步操作流程 |
| Subagents | 显式委派 | 隔离的 LLM | 读完即弃、会撑爆主上下文的监测/校验 |

判据：**跨阶段不变式 → Rules；必然机械动作 → Hook；阶段性多步流程 → Skill；读完即弃的重 context → Subagent。**
派生原则：能下沉到 Hook 的确定性逻辑，绝不写进 Rules 让 LLM 自觉。

各原语的具体清单见 `docs/详细设计.md` 第 2 节。

## 4. 目录结构

```
novel-generator/
├── package.json                    # workspace 根，scripts.install-into 一键安装
├── packages/
│   ├── novel-lifecycle-cli/        # @novel-generator/lifecycle-cli（硬层）
│   │   ├── bin/novel-cli           # 统一 CLI 分发器（shebang + chmod 755）
│   │   ├── src/
│   │   │   ├── core/
│   │   │   │   ├── db.py           # 唯一 sqlite3 访问点 + seal 守卫
│   │   │   │   └── schema/         # layer1~5 增量 SQL 分片
│   │   │   ├── novel/              # 小说级（init/stage/finalize/style）
│   │   │   ├── volume/             # 卷规划级（weave/cycle/presummary）
│   │   │   ├── chapter/            # 章写作级（prose）
│   │   │   └── elements/           # 创作元素管理（唯一入口 element_manager.py）
│   │   │       ├── element_manager.py   # 唯一分发入口
│   │   │       ├── nonlinear_db/   # 支线/伏笔/爽点/承诺/涌现/弧线处理器
│   │   │       ├── bible/          # Bible 派生视图渲染
│   │   │       └── context/        # 章级线索绑定
│   │   ├── tests/                  # test_layer1~5（硬层自测）
│   │   └── install-cli.js          # 硬层安装入口
│   └── novel-spec/                 # @novel-generator/spec（软层）
│       ├── skills/                 # 创世各阶段的多步流程
│       ├── agents/                 # 读完即弃的监测/校验
│       ├── hooks/                  # hook 脚本
│       ├── rules/                  # 跨阶段不变式（→ 目标项目 .claude/rules/）
│       ├── templates/
│       │   ├── CLAUDE.md           # 目标项目 CLAUDE.md 模板
│       │   └── introduce.md        # 工具使用导引模板
│       └── install-spec.js         # 软层安装入口
├── openspec/                       # 方法论规格（最慢变）
└── docs/                           # 文档
```
