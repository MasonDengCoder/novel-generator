# 创世观对应关系

> 本文档只描述一件事：**把《创作即创世》方法论融入 Claude Code 这个 LLM harness 时，发生了哪些变化、对架构设计产生了什么影响。**
> 方法论内核见本文档 §五；模块与目录的最终形态见 `docs/架构设计.md` 与 `docs/详细设计.md`；需求边界见 `docs/需求说明书.md`。

融合的核心问题是：方法论是写给"人类作者"的心法，而 Claude Code 提供的是 **Rules / Hooks / Skills / Subagents** 四个原语。把心法落到工具，就要回答两类问题——

1. 每个创世概念，应该由**哪个原语**承载？（本文档 §二）
2. 这个选择反过来**改变了架构的哪些部分**？（本文档 §三、§四）

---

## 一、融合的总原则：按"何时进入 context、由谁执行"分配原语

方法论里的每条规则，对人类作者只是"记住就好"，但对 LLM，"记住"是有成本的——常驻 context 既贵又会在长对话里漂忘。于是融合时按两个维度给原语定位：

| 原语 | 何时加载 | 由谁执行 | 适合承载的创世概念 |
|------|---------|---------|------------------|
| **Rules（CLAUDE.md）** | 每轮常驻 | LLM 自觉遵守 | 跨所有阶段、违反即崩的铁律 |
| **Hooks** | 事件触发 | 脚本（LLM 之外） | 必须每次确定性发生的机械动作 |
| **Skills** | 按需加载 | LLM 读后执行 | 某个创世阶段的多步操作流程 |
| **Subagents** | 显式委派 | 隔离的 LLM | 读完即弃、会撑爆主上下文的监测/校验 |

决策树（自上而下，命中即停）：

```
要不要 LLM 在任何阶段都背着、忘了就出错？ ── 是 → Rules（但必须短）
否 → 该不该靠 LLM 自觉、能否做成确定性脚本？ ── 是 → Hook
否 → 是不是某个特定阶段才触发的一套流程？ ── 是 → Skill
否 → 做完会不会留下一大堆对主线无用的 context？ ── 是 → Subagent
```

两条派生原则：

- **能下沉到 Hook 的确定性逻辑，绝不写进 Rules 让 LLM 自觉。** Rules 每多一条，每轮都付 token，且仍可能漂忘；Hook 是钢性的。
- **判断 Skill vs Subagent**：产出要回流主线供后续引用 → Skill；只回结论 → Subagent。

## 二、创世概念 → 承载原语（融合产生的映射）

| 创世概念 / 机制 | 承载原语 | 融合后的形态 |
|----------------|---------|-------------|
| **两条铁律**（大势不可改、遁去其一仍在四极） | Rules | LLM 做每个创作判断都背着的边界 |
| **软↔硬唯一接口**（只走 `novel-cli`） | Rules | 任何阶段不可违反的不变式 |
| **不可越级修正** | Rules | 贯穿四层的铁律 |
| **创世各阶段**（开天→编织→运行→封典） | Skill | 各阶段一份操作手册，产出回流主线 |
| **小轮回**（章间四相 + 残余） | Skill + Hook | 四相撰写归 `write-prose` skill；写前注入 threads 归 hook |
| **遁出四极监测**（写作中撞极） | Hook + Subagent | 撞极检查必须每章触发（hook）；比对推演交隔离的 `tiandao-monitor` |
| **大轮回**（卷末天道监测） | Subagent | 读整卷残余做对抗性推演，做完即弃 |
| **大势不可改的卷级落地**（卷必达目标硬门禁） | Hook + Subagent | PostToolUse hook 落章级收束遥测（`post-prose-converge-signal`，标记涌现是否拽离卷目标）；卷末 `target-convergence-verifier` subagent 硬判定目标达成、未达成阻断封卷，读完即弃 |
| **遁去其一处置闭环**（评分→决策→执行） | Subagent + Skill | 评分是重 context 读完即弃（`emergent-scorer` subagent）；处置决策与执行回流主线（`dispose-emergent` skill），结果改 presummary 与 arc 状态 |
| **dormant 角色重激活推测**（降 context 压力） | Subagent | `reactivation-inferer` 读完整 arc 历史 + 场景上下文推测角色当前态，下沉为 `is_inferred=1` 快照入库，此后只注入快照 |
| **四极/主线完整性校验** | Subagent | 一次性校验，只回 PASS/FAIL |

> 一句话判据：**跨阶段不变式 → Rules；必然机械动作 → Hook；阶段性多步流程 → Skill；读完即弃的重 context → Subagent。**

## 三、融合对硬层架构的影响

方法论里"记在脑子里"的概念，在硬层落成了**结构化数据**——因为 LLM 不可靠的记忆必须由确定性 DB 兜底。

| 创世概念 | 落成什么 | 为什么必须落成数据 |
|---------|---------|------------------|
| **3000 大道（主线·定数）** | `mainplot_nodes`（immutable）+ `volumes` 卷必达目标 + `target_convergence_signal` | 防止 LLM 长程写作悄悄改掉终局；卷目标硬门禁守住"大势不可改"——未达成阻断封卷，不设容差 |
| **800 旁门（可改小势）** | `subplot`/`foreshadowing`/`payoff`/`promise` | 跨数百章的伏笔，LLM 记不住，须台账化 |
| **遁去其一（变数）** | `emergent` + `arc`，带状态机 + 四维评分 | 涌现要走四级处置阶梯，须可查询当前状态与评分；重激活态下沉为 `is_inferred=1` 快照，避免每次重读全史 |
| **四极（边界）** | `world_boundaries` | 监测撞极时要有确定的红线可比对 |
| **小轮回残余** | `chapter_residue` + `phase_log` | 章末残余驱动下一章，须跨任务续接 |
| **大轮回** | `great_cycles` | 卷级天道监测的归档台账 |
| **封典** | `creation_cycle` + `creation_log_archive` | 终检与封档须可审计 |

**对四层轮回的影响**：方法论的四层轮回直接定义了硬层的 schema 分层（layer1 奠基 / layer2 编织 / layer3 写作 / layer4 封档）与 CLI 子命令的权限边界（章节级只能标记、卷级才能系统处置）。

**额外多出的一层**：方法论里没有的 **layer5 `chapter_threads`**，是融合产物——因为 LLM 写作时 context 有限，必须有个"按相关度把活跃元素绑定到本章"的横切层喂给它。这是"为 LLM 而生"的层，不属于四层轮回。

## 四、融合对软层与运行时的影响

- **"设定圣经"从文件变成视图**：人类作者会维护一份越写越厚的设定文档；融合后改为 `bible` 命令对 DB 的派生渲染（core/active/dormant/full），避免 LLM 去读一个不断膨胀、易过期的文件。
- **"天道监测"从作者的自我审视变成 subagent**：人类的大轮回是"以造物主视角回看一卷"；融合后交给隔离的监测 agent，避免把整卷回看的庞大 context 灌进主创作流程。
- **"留痕不修正"从心法变成 hook + 权限**：方法论说"章节级只标记残余不修正"，融合后由章节级 CLI 的权限边界（禁止 close/judge）+ 写前 hook 共同钢性保证，而非依赖 LLM 自律。

## 五、方法论内核（融入前的原貌）

> 本节是《创作即创世》方法论的浓缩内核与最初的口语化梳理，作为上述映射的来源记录保留。原独立散文文档已并入此处。

**核心公式**：

> 主线（3000 大道·不可改） + 支线/伏笔/爽点（800 旁门·可改） + 时间与轮回 + 人物角色（遁去其一之源） = 活着的世界

- **3000 大道（主线）** — 世界的"定数"，故事终局与核心冲突的必然走向，不可更改。
- **800 旁门（支线/伏笔/爽点）** — 世界的"小势"，可在人物意志介入下偏转。
- **时间与轮回** — 世界的"心跳"：时间注入则运行，轮回开启则自我修正进化。
- **遁去其一（人物）** — 模型的"灵魂"，变数之源；人物是在时间与轮回中自然生成的活变数，会做出计划外的行动。

**两大铁律**：

1. **大势不可改，小势可改** — 主角终将面对魔王（大势），路上先遇精灵还是矮人（小势）可调。
2. **遁去其一，仍在四极** — 角色可"野"，但绝不能颠覆世界基本法则（力量上限、道德底线等）。

**轮回**：

- **小轮回（章间心跳）** — 每章一个"生、住、异、灭"循环，章末留"残余"（悬念/情绪/新线索）驱动下一章。
- **大轮回（卷间修正）** — 每卷一次"天道监测"：识别涌现的遁去其一，吸收精彩意外、修补有害裂缝，温柔梳理而非扼杀野性。

**心法口诀**：

> 章节留痕，事件清淤，卷级定局，周期铸典。大势不改，小势可调，遁出四极，轮回护道。

**警示**：四极不可过死须留白；不可沉迷设定而不动笔；监测不可过度、勿抹杀意外之喜。

---

以下为方法论最初按创世阶段的口语化梳理：

**创世期** — 灵感（开天，生成 introduce）、设定（定四极，含时间/空间/世界观/社会观/文笔/敏感词限制）。

**法则生成期** — 主线（大道生成，涌现无名主角设定）、支线（旁门生成，涌现无名配角设定）。

**命运编织期** — 分卷（时间长河隔断）→ 卷分事件 → 事件分节（按位置/性质/时间断裂切分）→ 章节预设（谁参与、发生什么、达成什么、与主支线伏笔的关系）。

**世界运行期** — 据 rules + 进度管理 + 章节设定逐章撰写，涌现的新角色/事件/伏笔均须保存。

由此梳理出**三个生命周期**（创作周期 / 编织 / 世界运行的进度管理）与**两个数据管理系统**（生命周期管理 / 创作元素管理）。
